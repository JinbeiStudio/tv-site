Install it in a few steps.Installez-la en quelques étapes.

Open your device below.Ouvrez votre appareil ci-dessous.

Mac
  1. Download the file for your Mac: M1 + if your Mac has an M chip, otherwise Intel. (The first menu at the top left → About This Mac tells you.)
  2. Open the downloaded .zip, then drag Jinbei Studio into your Applications folder.
  3. The first time, right-click the app → Open → Open. macOS warns about it because the app is not from the App Store; this is expected.
  4. If it still refuses: System Settings → Privacy & Security → scroll down → Open Anyway.
  1. Téléchargez le fichier de votre Mac : M1 + si votre Mac a une puce M, sinon Intel. (Le premier menu en haut à gauche → À propos de ce Mac l’indique.)
  2. Ouvrez le fichier .zip, puis glissez Jinbei Studio dans votre dossier Applications.
  3. La première fois, faites clic droit sur l’app → Ouvrir → Ouvrir. macOS affiche un avertissement car l’app ne vient pas de l’App Store ; c’est normal.
  4. Si c’est encore refusé : Réglages Système → Confidentialité et sécurité → en bas → Ouvrir quand même.
Windows
  1. Download the installer and open it.
  2. If Windows shows “Windows protected your PC”, click More info → Run anyway. The app is not signed by Microsoft; this is expected.
  3. Follow the installer, then open Jinbei Studio from the Start menu.
  1. Téléchargez le programme d’installation et ouvrez-le.
  2. Si Windows affiche « Windows a protégé votre ordinateur », cliquez sur Informations complémentaires → Exécuter quand même. L’app n’est pas signée par Microsoft ; c’est normal.
  3. Suivez l’installation, puis ouvrez Jinbei Studio depuis le menu Démarrer.
Fire TV Stick
  1. On the Fire TV, install the free Downloader app (search for it in the Appstore).
  2. Go to Settings → My Fire TV → Developer options and turn on Install unknown apps for Downloader. (If you don’t see Developer options: Settings → My Fire TV → About, then press OK on the device name seven times.)
  3. Open Downloader and type this address in its box: github.com/JinbeiStudio/AIOStreams/releases/latest, then Go. On the page that opens, choose the file ending in armeabi-v7a.apk.
  4. When the download ends, choose Install, then Open.
Not sure which Fire TV you have? Use the armeabi-v7a file: it works on all Fire TV Sticks.
  1. Sur la Fire TV, installez l’app gratuite Downloader (cherchez-la dans l’Appstore).
  2. Allez dans Paramètres → Ma Fire TV → Options pour les développeurs et activez Installer des applications inconnues pour Downloader. (Si vous ne voyez pas les options développeur : Paramètres → Ma Fire TV → À propos, puis appuyez sept fois sur OK sur le nom de l’appareil.)
  3. Ouvrez Downloader et saisissez cette adresse : github.com/JinbeiStudio/AIOStreams/releases/latest, puis Go. Sur la page qui s’ouvre, choisissez le fichier qui finit par armeabi-v7a.apk.
  4. Une fois le téléchargement terminé, choisissez Installer, puis Ouvrir.
Vous ne savez pas quelle Fire TV vous avez ? Prenez le fichier armeabi-v7a : il fonctionne sur toutes les Fire TV Stick.
Android (phone, tablet, Android TV)
  1. Download the arm64-v8a.apk file (it suits almost every phone and tablet made in the last years).
  2. Open it. Android asks to allow installs from your browser or file manager: accept, then Install.
  3. If Play Protect warns about the app, choose Install anyway.
  4. On Android TV or Google TV, install Downloader and follow the Fire TV steps above.
  1. Téléchargez le fichier arm64-v8a.apk (il convient à presque tous les téléphones et tablettes récents).
  2. Ouvrez-le. Android demande d’autoriser les installations depuis votre navigateur ou gestionnaire de fichiers : acceptez, puis Installer.
  3. Si Play Protect avertit à propos de l’app, choisissez Installer quand même.
  4. Sur Android TV ou Google TV, installez Downloader et suivez les étapes de la Fire TV ci-dessus.
LG TV (webOS)
  1. On the TV, open the LG Content Store, install Developer Mode, and sign in with a free LG developer account (webostv.developer.lge.com).
  2. In the Developer Mode app turn on Dev Mode Status and Key Server. The TV restarts. Note the TV’s IP address shown there.
  3. On a computer, install Dev Manager (webosbrew/dev-manager-desktop), add your TV with its IP address, and follow its pairing steps.
  4. In Dev Manager, open the Apps tab, choose Install IPK and select the downloaded .ipk file.
  5. Open Jinbei Studio from the TV’s app list.
The developer session expires after a while: open the Developer Mode app on the TV and extend it when it says so. Apps you installed stay.
  1. Sur la TV, ouvrez le LG Content Store, installez Developer Mode, et connectez-vous avec un compte développeur LG gratuit (webostv.developer.lge.com).
  2. Dans l’app Developer Mode, activez Dev Mode Status et Key Server. La TV redémarre. Notez l’adresse IP de la TV affichée.
  3. Sur un ordinateur, installez Dev Manager (webosbrew/dev-manager-desktop), ajoutez votre TV avec son adresse IP et suivez l’appairage.
  4. Dans Dev Manager, onglet Apps, choisissez Install IPK et sélectionnez le fichier .ipk téléchargé.
  5. Ouvrez Jinbei Studio depuis la liste des apps de la TV.
La session développeur expire au bout d’un moment : ouvrez l’app Developer Mode sur la TV et prolongez-la quand elle le demande. Les apps installées restent.
Samsung TV (Tizen)
  1. On the TV: Apps → press 1 2 3 4 5 → turn on Developer mode and enter your computer’s IP address. Restart the TV.
  2. On a computer, install Tizen Studio (developer.tizen.org) with the TV Extensions.
  3. In Device Manager, connect to the TV’s IP address. In Certificate Manager, create a Samsung certificate (free Samsung account) that includes your TV.
  4. Resign and install the downloaded .wgt with your certificate (Tizen Studio: Tools → Package Manager, or the tizen install command).
This is the longest way in. Ask Julien for help if you get stuck.
  1. Sur la TV : Apps → tapez 1 2 3 4 5 → activez le mode développeur et saisissez l’adresse IP de votre ordinateur. Redémarrez la TV.
  2. Sur un ordinateur, installez Tizen Studio (developer.tizen.org) avec les TV Extensions.
  3. Dans Device Manager, connectez-vous à l’adresse IP de la TV. Dans Certificate Manager, créez un certificat Samsung (compte Samsung gratuit) incluant votre TV.
  4. Resignez et installez le fichier .wgt téléchargé avec votre certificat (Tizen Studio : Tools → Package Manager, ou la commande tizen install).
C’est la méthode la plus longue. Demandez de l’aide à Julien si vous bloquez.
Linux
  1. Download the .flatpak file for your processor.
  2. In a terminal: flatpak install --user ./jinbei-studio-linux-x64.flatpak (use the name of the file you downloaded).
  3. Run it with flatpak run followed by the app’s name, or from your applications menu.
  1. Téléchargez le fichier .flatpak correspondant à votre processeur.
  2. Dans un terminal : flatpak install --user ./jinbei-studio-linux-x64.flatpak (avec le nom du fichier téléchargé).
  3. Lancez-la depuis le menu des applications.
